How the rankings work +

Data comes first

Requires 253 aligned daily OHLCV bars and average 20-session dollar volume of at least $1M. Only stocks ending on the latest loaded session are compared. Older files are excluded; the latest session itself may still be stale or incomplete.

Growth momentum

Positive 252-session return and Close > SMA50 > SMA200. Score: 40% annual momentum, 30% half-year momentum, 20% distance above SMA200, 10% low volatility.

Swing watchlist

Close > SMA50, positive 20-session return, and Close between one ATR below and two ATR above the prior 20-session high. Score: 40% short momentum, 35% breakout position, 25% relative volume.

Read the score in context

Each component uses a percentile among its screen's candidates. No sector diversification or backtested performance is implied. Chart links show hourly High; scores and sparklines use daily Close. Sparklines show the latest 60 saved sessions, scaled independently.

Manage daily data +

Populate saved daily files from the project directory:

uv run --locked python download_sp500.py --resolution daily

Existing daily files are reused; explicitly adding --refresh replaces daily history. The explorer's market-update button updates hourly data only. Scanning does not refresh market data.
